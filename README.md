# Система мониторинга давления в реакторе 
## Постановка задачи
Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру «давление» (X). Программа преобразует измеряемые значения в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и статистический анализ выборки.

### Входные данные:
*   Параметр X: давление в реакторе, измеряется в барах.
*   Диапазон X: от 1 до 6 об/мин.
*   Количество измерений в выборке: N = 60.

### Формула преобразования Q(X):
$$Q(x) = \begin{cases}
5\sqrt{x-1.2}+5, & x < 2.2 \\
2(x-3.2)+50, & 2.2 \le x \le 4.2 \\
4\ln(x-2.2)+60, & x > 4.2
\end{cases}$$


### Ручной расчет (Примеры):
1. X = 1.3 (меньше 2.2): Q = 5·√(1.3−2.2+1) + 5 = 6.5811
2. X = 3.1 (в диапазоне 2.2-4.2): Q = 2·(X−3.2) + 50 = 49.8000
3. X = 4.5 (больше 4.2): Q = 4·ln(X−4.2+2) + 60 = 63.3316
